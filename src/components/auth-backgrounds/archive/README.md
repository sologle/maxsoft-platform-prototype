# Архив вариантов фона MaxSoft

Владелец выбрал MaxSoft основным 05.09.2026. Здесь сохранены прежние Тишина, Эхо, Шёлк, След, Живое и гостевая главная с карточкой. Фабрика Живого переиспользует общий `../field-scene.ts`.

[Открыть архив](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=minimal). Для просмотра форм замените `page=landing` на `page=login`. В архивном picker основной MaxSoft оставлен как референс сравнения.

Код, CSS и старая главная подключаются через React.lazy при явном открытии архива. Обычная ссылка и старые ссылки только с `background` открывают выбранный основной MaxSoft без панели сравнения.

Эксперимент №07 [«Разлёт»](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=scatter) хранится в `scatter-scene.ts`. Он переиспользует маску MaxSoft и Canvas renderer, но имеет собственную физику: импульс вдоль траектории указателя, разброс силы, вращение, короткий след и затухающие пружины возврата. Курсор в покое не удерживает частицы. Сборка 0.9 с / штрихи 1.8 px сохранены, reduced-motion сразу рисует неподвижную надпись. За формами используется общий `createAmbientField`.

В эксперименте кнопка «Настроить разлёт» открывает семь регуляторов: сила, радиус, сила возврата, затухание, вращение, длина следа и разброс между штрихами. Изменения применяются на лету без перезапуска сцены и сохраняются в этом браузере. «Скопировать настройки» выдаёт JSON с меткой `maxsoft-scatter-v1`, который можно отправить для дальнейшей настройки; при запрете clipboard доступен текст для ручного копирования. «Сбросить настройки» возвращает исходные значения. Панель можно свернуть.
