# Архив вариантов фона MaxSoft

Главная использует выбранную владельцем сцену «Разлёт» с фиксированным набором из `../scatter-preset.ts`. Её физика в `../scatter-scene.ts` общая с №07, панель и хранилище экспериментальных настроек остаются здесь.

[Открыть архив](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=minimal). Сохранены №01–05, прежний основной MaxSoft №06 и экспериментальная панель №07. Для форм замените `page=landing` на `page=login`. Код, CSS и главная с карточкой загружаются через React.lazy при `backgroundArchive=1`; обычная ссылка всегда открывает выбранную сцену без панелей.

[Настроить №07](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=scatter): девять регуляторов с описаниями, живым применением, сохранением в браузере и экспортом `maxsoft-scatter-v2`. Главная не читает эти сохранённые значения. Семь параметров прежнего формата продолжают поддерживаться; отсутствующие параметры орбиты берутся из UI-пресета. При запрете clipboard доступно ручное копирование.

Новый набор при первом открытии и сбросе: force 0.3, radius 0.55, spring 20, damping 3.8, spin 0.8, trail 0, variation 1, orbitRadius 60, orbitStrength 0.6. Сохранённые пользовательские значения остаются до изменения или сброса.

Сборка надписи — 0.9 с. На ширине <640 px штрихи 1.2 px и каждый пятый штрих букв отключён, на desktop — 1.8 px и прежняя плотность. Движение пальцем действует как мышь, отпускание/отмена возвращают буквы; pinch zoom, прокрутка форм/панели и reduced-motion сохраняются. За формами общий `createAmbientField` без надписи.
