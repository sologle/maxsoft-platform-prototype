# Архив вариантов фона MaxSoft

Владелец выбрал MaxSoft основным 05.09.2026. Здесь сохранены прежние Тишина, Эхо, Шёлк, След, Живое и гостевая главная с карточкой. Фабрика Живого переиспользует общий `../field-scene.ts`.

[Открыть архив](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=minimal). Для просмотра форм замените `page=landing` на `page=login`. В архивном picker основной MaxSoft оставлен как референс сравнения.

Код, CSS и старая главная подключаются через React.lazy при явном открытии архива. Обычная ссылка и старые ссылки только с `background` открывают выбранный основной MaxSoft без панели сравнения.

Эксперимент №07 [«Разлёт»](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=scatter) хранится в `scatter-scene.ts`. Он переиспользует маску MaxSoft и Canvas renderer, но имеет собственную физику: импульс вдоль траектории указателя, разброс силы, вращение, короткий след и затухающие пружины возврата. Неподвижный курсор удерживает штрихи в мягкой полосе вокруг выбранного радиуса; после ухода указателя пружины собирают надпись. Стартовый набор выбран владельцем: толчок 20%, область 65%, тяга 20, торможение 6.3, круг 60 px и удержание 70%; вращение, след и неравномерность — 100%. Сборка 0.9 с; штрихи 1.8 px, на экранах уже 640 px — 1.2 px, reduced-motion сразу рисует неподвижную надпись. За формами используется общий `createAmbientField`.

В эксперименте кнопка «Настроить разлёт» открывает девять регуляторов в четырёх группах: круг вокруг мыши, разлёт при движении, возвращение на место и вид палочек. Добавлены расстояние от курсора в px и удержание на круге в процентах. Все прежние параметры сохранены, названы проще и снабжены описанием эффекта больших/малых значений. Изменения применяются на лету без перезапуска сцены и сохраняются в этом браузере. «Скопировать настройки» выдаёт JSON с меткой `maxsoft-scatter-v2`, который можно отправить для дальнейшей настройки; при запрете clipboard доступен текст для ручного копирования. «Сбросить настройки» возвращает исходные значения. Панель можно свернуть.

Ранее сохранённые семь параметров подхватываются из прежнего ключа хранения; к ним добавляются настройки орбиты. «Сбросить настройки» применяет выбранный владельцем набор выше. Уже сохранённые пользовательские значения остаются до изменения или сброса.

На главной MaxSoft и в эксперименте движение пальцем управляет фоном, отпускание возвращает надпись. На полноэкранной сцене `touch-action: pinch-zoom` отдаёт одиночный жест обработчикам Pointer Events; прокрутка форм и панели настроек остаётся штатной.
