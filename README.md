# MaxSoft — кликабельный прототип платформы

Самостоятельный нативный React-прототип портала для демонстрации заказчику. Единый интерфейс автоматически адаптируется к ширине экрана, открывается с гостевой главной и поддерживает переключение шести ролей в панели сценариев, рабочие формы, деревья, меню, модальные окна и выдвижные панели. Данные демонстрационные — реальный backend пока не подключён.

Демо: <https://sologle.github.io/maxsoft-platform-prototype/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run e2e
```

База знаний и реестр файлов поддерживают таблицу и крупные карточки. Предпросмотр предусмотрен только для PDF/DOCX; остальные форматы скачиваются. Доступ настраивается в «Администрирование → Доступ к материалам» по типу компании и сохраняется в хранилище браузера.

## Основной вариант и архив фонов

[Открыть портал](https://sologle.github.io/maxsoft-platform-prototype/) — выбранный владельцем MaxSoft. Надпись из штрихов толщиной 1.8 px собирается за 0.9 с; под ней две полупрозрачные кнопки с лёгким увеличением при наведении. За формами входа, регистрации и восстановления пароля свободно движутся крупные редкие штрихи без надписи. Влияние курсора мягкое; обе темы и reduced-motion поддержаны.

[Открыть архив вариантов](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=minimal). Пять предыдущих вариантов сохранены в `src/components/auth-backgrounds/archive/` и загружаются только при открытии архива. В архивном переключателе MaxSoft доступен как основной вариант для сравнения.

- `background=minimal` — «Тишина»: мягкий свет и тонкая сетка.
- `background=echo` — «Эхо»: волны от курсора деформируют точечную поверхность.
- `background=silk` — «Шёлк»: нити тянутся к курсору и упруго возвращаются.
- `background=ribbon` — «След»: световые ленты рисуют за мышью и гаснут.
- `background=living-field` — «Живое»: вращение штрихов, орбита у мыши и сборка MaxSoft в паузах.
- `background=scatter` — эксперимент «Разлёт»: взмах мыши разбрасывает штрихи надписи с инерцией, вращением и коротким следом; рядом с неподвижным курсором они держатся на орбите, а после его ухода возвращаются в буквы. За формами остаётся спокойное поле без надписи.

[Открыть эксперимент «Разлёт»](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&backgroundArchive=1&background=scatter). Основной вариант доступен по прежней ссылке и в пункте 06 для сравнения.

Архив включается только параметром `backgroundArchive=1`; `background` выбирает сцену внутри него. Оба параметра сохраняются в гостевых переходах и удаляются после входа. Без флага архива всегда используется основной MaxSoft, панель сравнения скрыта. [Вернуться к основному варианту](https://sologle.github.io/maxsoft-platform-prototype/).

Общий Canvas2D renderer учитывает плотность пикселей, ограничивает объём отрисовки и останавливается при reduced-motion/скрытой вкладке. Новых зависимостей и WebGL нет.

В эксперименте кнопка «Настроить разлёт» открывает девять регуляторов в четырёх группах: круг вокруг мыши, разлёт при движении, возвращение на место и вид палочек. Добавлены расстояние от курсора в px и удержание на круге в процентах. Все прежние параметры сохранены, названы проще и снабжены описанием эффекта больших/малых значений. Изменения применяются на лету без перезапуска сцены и сохраняются в этом браузере. «Скопировать настройки» выдаёт JSON с меткой `maxsoft-scatter-v2`, который можно отправить для дальнейшей настройки; при запрете clipboard доступен текст для ручного копирования. «Сбросить настройки» возвращает исходные значения. Панель можно свернуть.

Ранее сохранённые семь параметров подхватываются из прежнего ключа хранения; к ним добавляются настройки орбиты. «Сбросить настройки» применяет выбранный владельцем набор выше. Уже сохранённые пользовательские значения остаются до изменения или сброса.

На главной MaxSoft и в эксперименте движение пальцем управляет фоном, отпускание возвращает надпись. На полноэкранной сцене `touch-action: pinch-zoom` отдаёт одиночный жест обработчикам Pointer Events; прокрутка форм и панели настроек остаётся штатной.
