# MaxSoft — кликабельный прототип этапа 1

Самостоятельный React-прототип портала для демонстрации заказчику. Он воспроизводит desktop- и mobile-макеты этапа 1, поддерживает шесть ролевых точек входа и работает только на статических демонстрационных данных — реального backend и сохранения данных здесь нет.

Демо: <https://sologle.github.io/maxsoft-stage1-prototype/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run e2e
```
