# MaxSoft — кликабельный прототип платформы

Самостоятельный нативный React-прототип портала для демонстрации заказчику. Единый интерфейс автоматически адаптируется к ширине экрана, поддерживает шесть ролевых точек входа, рабочие формы, деревья, меню, модальные окна и выдвижные панели. Данные демонстрационные — реальный backend пока не подключён.

Демо: <https://sologle.github.io/maxsoft-platform-prototype/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run e2e
```
