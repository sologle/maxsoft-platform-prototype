# MaxSoft — кликабельный прототип платформы

Самостоятельный React-прототип портала для демонстрации заказчику. Он воспроизводит desktop- и mobile-макеты платформы, поддерживает шесть ролевых точек входа и работает только на статических демонстрационных данных — реального backend и сохранения данных здесь нет.

Демо: <https://sologle.github.io/maxsoft-platform-prototype/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run e2e
```
