# MaxSoft — кликабельный прототип платформы

Самостоятельный нативный React-прототип портала для демонстрации заказчику. Единый интерфейс автоматически адаптируется к ширине экрана, открывается с гостевой главной и поддерживает переключение шести ролей в панели сценариев, рабочие формы, деревья, меню, модальные окна и выдвижные панели. Данные демонстрационные — реальный backend пока не подключён.

Демо: <https://sologle.github.io/maxsoft-platform-prototype/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run e2e
```

База знаний и реестр файлов поддерживают таблицу и крупные карточки. Предпросмотр предусмотрен только для PDF/DOCX; остальные форматы скачиваются. Доступ настраивается в «Администрирование → Доступ к материалам» по типу компании и сохраняется в хранилище браузера.

## Выбор фона до входа

[Открыть сравнение четырёх вариантов](https://sologle.github.io/maxsoft-platform-prototype/?page=login&role=guest&background=minimal). Кнопки сверху переключают графику без сброса формы; переключатель темы находится справа.

- `background=minimal` — «Тишина», текущий минимальный фон.
- `background=flow` — «Поток», тонкие движущиеся линии.
- `background=prism` — «Призма», объёмная стеклянная геометрия.
- `background=orbit` — «Орбита», цифровая сфера, частицы и световые траектории.

Параметр работает на общей гостевой сцене (главная, вход, регистрация, восстановление), сохраняется при переходах до входа. Без параметра панель сравнения скрыта. Все варианты учитывают `prefers-reduced-motion`; новых зависимостей и WebGL нет.
