# MaxSoft — кликабельный прототип платформы

Самостоятельный нативный React-прототип портала для демонстрации заказчику. Единый интерфейс автоматически адаптируется к ширине экрана, открывается с гостевой главной и поддерживает переключение шести ролей в панели сценариев, рабочие формы, деревья, меню, модальные окна и выдвижные панели. Данные демонстрационные — реальный backend пока не подключён.

Демо: <https://sologle.github.io/maxsoft-platform-prototype/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run e2e
```

База знаний и реестр файлов поддерживают таблицу и крупные карточки. Предпросмотр предусмотрен только для PDF/DOCX; остальные форматы скачиваются. Доступ настраивается в «Администрирование → Доступ к материалам» по типу компании и сохраняется в хранилище браузера.

## Выбор фона до входа

[Открыть сравнение шести вариантов](https://sologle.github.io/maxsoft-platform-prototype/?page=login&role=guest&background=minimal). Кнопки сверху переключают графику без сброса формы; переключатель темы находится справа.

- `background=minimal` — «Тишина», текущий минимальный фон.
- `background=echo` — «Эхо»: волны от курсора деформируют точечную поверхность.
- `background=silk` — «Шёлк»: нити тянутся к курсору и упруго возвращаются.
- `background=ribbon` — «След»: световые ленты рисуют за мышью и гаснут.
- `background=living-field` — «Живое»: медленное вращение штрихов, орбита у мыши и сборка MaxSoft в паузах.
- `background=wordmark` — «MaxSoft»: надпись из живых штрихов по центру, собирающаяся за 0.9 с, с мягкой локальной реакцией. [Отдельная главная с двумя кнопками](https://sologle.github.io/maxsoft-platform-prototype/?page=landing&role=guest&background=wordmark) показывает только полупрозрачные «Войти» и «Регистрация» с лёгким увеличением при наведении; за формами входа, регистрации и восстановления пароля крупные штрихи свободно движутся без надписи.

Параметр работает на общей гостевой сцене (главная, вход, регистрация, восстановление), сохраняется при переходах до входа. Без параметра панель сравнения скрыта. Первые пять фонов сохранены; шестая композиция добавлена 05.09.2026. Во втором–четвёртом вариантах реакция локальная, общего параллакса нет. Canvas2D учитывает плотность пикселей и ограничивает объём отрисовки; reduced-motion отключает цикл анимации. Новых зависимостей и WebGL нет.
