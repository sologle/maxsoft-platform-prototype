# MaxSoft — кликабельный прототип платформы

Самостоятельный нативный React-прототип портала для демонстрации заказчику. Единый интерфейс автоматически адаптируется к ширине экрана, открывается с гостевой главной и поддерживает переключение шести ролей в панели сценариев, рабочие формы, деревья, меню, модальные окна и выдвижные панели. Данные демонстрационные — реальный backend пока не подключён.

Демо: <https://sologle.github.io/maxsoft-platform-prototype/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run e2e
```

База знаний и реестр файлов поддерживают таблицу и крупные карточки. Предпросмотр предусмотрен только для PDF/DOCX; остальные форматы скачиваются. Доступ настраивается в «Администрирование → Доступ к материалам» по типу компании и сохраняется в хранилище браузера.
